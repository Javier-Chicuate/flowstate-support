Frequently asked questions

Does my plan sync between devices?

This version keeps each device's planner locally. Use Settings → Data to export and import a backup. Optional Calendar and Reminders integrations use the accounts configured on your device.

How do I enable Calendar or Reminders?

Open Flowstate Settings, connect the service and grant access. Enable two-way sync only if you want linked records updated in both apps. Permissions can be revoked in device settings.

How do I back up my data?

Choose Settings → Data → Export backup. Keep the file safe: Flowstate does not encrypt exports. Importing merges records rather than deleting existing ones.

How do I delete data?

Use item deletion controls. Disable sync before deleting local items if you want to keep external Calendar or Reminders copies. Delete exports, system backups and records in other services separately. There is no Flowstate account or remote planner database.

Why is voice input unavailable?

Voice input is offered on iPhone and iPad and needs microphone and Speech Recognition permission. Availability varies by device and language. Apple may process audio remotely when on-device recognition is unavailable.

Does Flowstate block apps?

The Mac focus feature can hide selected apps. This version does not block apps on iPhone.
